# Install

## Quick install

Use the install script or install via Cargo:

=== ":octicons-terminal-16: Shell"

    ```console
    $ curl -fsSL https://statespace.com/install.sh | sh
    ```

=== ":simple-rust: Cargo"

    ```console
    $ cargo install statespace
    ```

## Verify installation

Check that Statespace is installed correctly:

```console
$ statespace --version
```
